# 果映手机版

基于电视版代码的竖屏手机界面，作为 `phone` 构建变体提供；包名 `io.github.tsukiyo_zero.guoyingtv.phone`，可与电视版同时安装。支持 Android 6.0 及以上。

## 构建

```bash
./gradlew :app:assemblePhoneRelease   # 手机版
./gradlew :app:assembleTvRelease      # 电视版（原 assembleRelease）
```

产物位于 `app/build/outputs/apk/phone/release/`。未配置 `keystore.properties` 或签名环境变量时，release 包使用调试签名。

## 界面

- 底部导航：推荐、找剧、排行、我的；搜索、详情、播放页按栈叠加，返回键逐层退出。
- 推荐：上下滑动换剧并自动试看首集，可切换推荐/漫剧/真人剧，下一部提前预加载。
- 找剧：组合筛选与三列海报网格，滚动续页；搜索支持历史与输入联想。
- 排行：综合、真人剧、漫剧、AI 剧四个热播榜。
- 我的：继续观看、收藏（均保存在本机）、最高清晰度。
- 播放：全屏竖屏，上下滑切集，进度条、倍速、清晰度、选集面板、横屏切换。

## 连播

当前集稳定播放且缓冲充足后，后台按单集请求下一集的播放信息与 MP4 索引，并追加到 ExoPlayer 播放列表；本集结束时无缝接续，手动切到下一集也直接复用。手机版始终连播。播放信息空响应或网络错误会自动重试 4 次（1.5/3/6/12 秒）。

## 与电视版的差异

- 不含应用内更新（避免被电视版更新包覆盖）与账号登录、弹幕评论。
- 代码位于 `app/src/phone`，复用 `app/src/main` 的数据、试播、取流、本机片单与封面加载；电视版入口与更新组件移至 `app/src/tv` 清单。
